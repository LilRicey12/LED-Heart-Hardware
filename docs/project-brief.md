# LED Heart Project Brief

## Project Name

Hardware-Only Sequential LED Heart

## Project Purpose

Design and construct a heart-shaped sequential LED display as my first engineering portfolio project.

The project will be built using hardware timing and digital logic rather than a programmable microcontroller. It will demonstrate circuit design, prototyping, testing, troubleshooting, soldering, permanent construction, and technical documentation.

## Intended Outcome

The finished device will display a repeating sequence of orange LEDs arranged in a heart shape.

The electronics will be concealed within a clean enclosure or backing structure, while the LEDs remain visible from the front.

## Core Architecture

The planned system consists of:

1. Battery-powered supply
2. 555 timer configured as an oscillator
3. CD4017 decade counter
4. LED output and current-limiting circuitry
5. Heart-shaped LED arrangement
6. Permanent perfboard construction
7. Finished enclosure or mounting structure

## Primary Requirements

* The sequencing system must operate without a microcontroller.
* The LEDs must illuminate in a predictable repeating sequence.
* LED current must remain within safe operating limits.
* The circuit must operate reliably from the selected power source.
* The final assembly must conceal most wiring and electronics.
* The battery and power switch must remain accessible.
* The project must be documented throughout development.

## Design Goals

* Use approximately 20 orange LEDs.
* Produce a single moving or comet-like lighting sequence.
* Maintain reasonably consistent LED brightness.
* Keep the circuit understandable and serviceable.
* Build and test individual circuit sections before combining them.
* Create a final result suitable for an engineering portfolio and job fair.

## Constraints

* This is my first permanent hardware-only electronics project.
* The circuit will initially be developed using a breadboard.
* Final construction will likely use perfboard.
* Component choices may be limited by parts already purchased.
* The enclosure must be achievable with my current fabrication skills.
* The circuit should avoid unnecessary complexity.

## Success Criteria

The project will be considered successful when:

* The complete LED sequence operates correctly.
* The circuit starts reliably when powered.
* No components overheat during extended operation.
* The soldered assembly passes continuity and functional testing.
* The enclosure protects and conceals the electronics.
* The final appearance is clean enough for portfolio presentation.
* The design process, failures, revisions, and results are documented.

## Planned Development Stages

1. Define requirements and desired LED behaviour.
2. Learn and test the 555 timer circuit.
3. Learn and test the CD4017 counter.
4. Test individual LED output stages.
5. Combine the timing and counter circuits.
6. Develop the complete breadboard prototype.
7. Create the final schematic.
8. Plan the perfboard layout.
9. Assemble and solder the permanent circuit.
10. Test and troubleshoot the permanent assembly.
11. Build and install the enclosure.
12. Perform final validation and portfolio documentation.

## Current Status

The project folder structure and documentation system have been created. Circuit development has not yet begun.
