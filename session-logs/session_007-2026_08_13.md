## Engineering Decisions

### Decision Made

I changed the logic of how the heart will look. This involves using a bigger perfboard then planned. I also will not being using a handoff, instead use two CD4017 to have to seperate sequences of LEDs. I will not be making a faceplate out of wood, this will leave the front of the perfboard with the LED visible

### Reasoning

First why not a handoff? Well trying to design the handoff I ran into the issue I need some sort of flip-flop, whether I use transistors or a CD4013. I can't use the CD4013 as this project has a deadline and I won't be able to get the component in fast enough. I can't use transistors mostly because they are fairly complex, I plan to learn how to use them in a seperate project. I'm already learning ALOT as this is my first project so throwing in learning transistor is not feasibly. I'm going to use a bigger perfboard to be able to seperate the LED more this will make the soldering and wiring easier. I originally planned to make a wooden face plate with the LED poking through, however my wood working skills are not at that level, and once again I don't have the time to learn
