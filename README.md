# Hardware-Only Sequential LED Heart

## Project Status

Final Build

## Project Overview

This project involves designing and constructing a heart-shaped sequential LED display using hardware timing and digital logic rather than a programmable microcontroller.

A 555 timer will generate the clock signal, and a CD4017 decade counter will control the LED sequence. The final circuit will be transferred from a breadboard prototype to permanent construction and installed in a finished enclosure.

## Project Goals

* Design a repeating sequential LED effect
* Build the circuit without a microcontroller
* Learn how the 555 timer and CD4017 operate
* Test each circuit subsystem independently
* Transfer the working design to perfboard
* Produce a clean and reliable final assembly
* Document the complete engineering process

## Planned System

Power supply → 555 timer → CD4017 counter → LED output circuitry → Heart-shaped display
